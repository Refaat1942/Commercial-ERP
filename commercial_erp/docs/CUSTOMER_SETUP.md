# تجهيز النظام لعميل (بيع + مخزون + حسابات) — دليل خطوة بخطوة

## الموديولات اللي بتشتغل عليها
| الموديول (من الشريط الجانبي) | بيخدم إيه | لازم؟ |
|---|---|---|
| **المبيعات** | فواتير بيع، عملاء، أسعار، مرتجعات، نقطة بيع | ✅ |
| **المشتريات** | فواتير شراء، موردين، أوامر شراء | ✅ |
| **المخزون** | أصناف، مخازن، جرد، حركات، تقارير الأرصدة | ✅ |
| **الحسابات** | سندات القبض والدفع، القيود، الأرباح والخسائر، الضرائب | ✅ |
| **الإعدادات** | الشركة، المستخدمين، الطباعة، إعدادات النظام | مرة واحدة في البداية |
| *التصنيع / المشاريع / الأصول / الجودة / CRM / الدعم* | مخفية عن عمد (مش للمحل الواحد) | ❌ لو العميل احتاجها بنفعّلها له |

## أولًا: قبل ما تقابل العميل (مرة واحدة على السيرفر)
1. ثبّت النظام (`docs/DEPLOYMENT.md`) واختَر اسم الشركة واختصارها.
2. للعرض عليه: اعمل **رابط تجربة** (الموقع التجريبي — `docs/DEMO.md`) بدل ما تفتح بيانات حقيقية.

## ثانيًا: الإعداد الأولي للعميل (حوالي ساعة)
1. **الشركة** (الإعدادات ← الشركة): الاسم، الرقم الضريبي لو موجود، العملة **جنيه (EGP)**. السنة المالية بتتعمل مع المعالج.
2. **المستخدمون** (الإعدادات ← المستخدمون): أنشئ مستخدم لكل شخص واختار *ملف الدور*: مالك / كاشير / أمين مخزن / محاسب. الكاشير يبيع ويقبض بس؛ المحاسب يشوف الحسابات؛ أمين المخزن للحركات والجرد.
3. **المخازن** (المخزون ← المخازن): سمّ مخزن المحل (ومخزن المستودع لو فيه). المخزن الافتراضي بيتحط تلقائي في الفواتير.
4. **طرق الدفع** (الحسابات ← طريقة الدفع): نقدي، فودافون كاش، إنستاباي، شيك، تحويل بنكي موجودين. ربط حساب بنك العميل من «حساب بنكي».
5. **الأصناف** (المخزون ← الأصناف):
   - مجموعات الأصناف (مواد غذائية، منظفات…) ← وحدات القياس (علبة، كرتونة…).
   - كل صنف: الكود، الاسم، المجموعة، الوحدة، **الباركود**، سعر البيع، **حد إعادة الطلب** (عشان يظهر في «أصناف تحت حد الطلب»).
   - لو عندك ملف إكسل: *الإعدادات ← استيراد بيانات* (Data Import) وارفع الأصناف دفعة واحدة.
6. **رصيد أول المدة للمخزون**: المخزون ← جرد المخزون ← الغرض «رصيد افتتاحي»، واكتب الكمية وسعر التكلفة لكل صنف. اعتمده (Submit).
7. **العملاء والموردون**: أضفهم (أو استوردهم). الأرصدة الافتتاحية: لكل طرف «فاتورة افتتاحية» أو قيد يومية بتاريخ أول المدة (وراجع المحاسب).
8. **الضرائب (اختياري)**: لو العميل مسجّل في ضريبة القيمة المضافة اختار في الفاتورة قالب «ضريبة القيمة المضافة 14%». لو مش مسجّل سيب القالب فاضي. راجع المحاسب على الأصناف المعفاة أو الجداول.
9. **الطباعة**: نموذج «فاتورة مبيعات - عربي» جاهز. غيّر الترويسة (اسم المحل/اللوجو) من «ترويسة الطباعة».

## ثالثًا: اختبار قبل التسليم (15 دقيقة)
1. فاتورة بيع كاش لعميل نقدي (مع «تحديث المخزون») ← اعتمد ← سند قبض ← اتأكد إن المخزون نقص والخزينة زادت (تقرير أرصدة المخزون + دفتر الأستاذ).
2. فاتورة شراء من مورد ← اعتمد ← اتأكد إن المخزون زاد والمستحق ظهر في «أرصدة الموردين».
3. مرتجع بيع (من الفاتورة: إنشاء ← مرتجع).
4. بيع آجل لعميل ← سند قبض جزئي ← اتأكد من «أرصدة العملاء».
5. تقرير «الأرباح والخسائر» و«أصناف تحت حد الطلب».

## رابعًا: التسليم
- **نسخة احتياطية**: تلقائية يوميًا 02:30؛ وريّه مكانها (`/var/backups/commercial-erp`) وإزاي تنسخها برّه السيرفر (`docs/OPERATIONS.md`).
- **HTTPS + دومين** قبل ما العميل يدخل بيانات حقيقية (`docs/DEPLOYMENT.md`).
- درّب الكاشير على فاتورة البيع والمرتجع، وأمين المخزن على الجرد وتقرير تحت حد الطلب، والمحاسب على التقارير.
- «دليل المصطلحات» جوّه النظام (أول عنصر في الشريط الجانبي) بيشرح كل كلمة محاسبية بالبلدي.

## مهم
- كل البيانات التجريبية (`demo.seed`) تتمسح قبل التسليم: `bench --site SITE execute commercial_erp.setup.demo.clear`.
- ما تفعّلش «رابط تجربة» على موقع العميل الحقيقي؛ النظام نفسه بيرفض (مفعّل بس على الموقع التجريبي).
